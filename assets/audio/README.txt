FOLDER AUDIO — UNTUK ARTIST
===========================

Taruh semua file suara (.ogg atau .wav) di folder ini.

Semua hook audio sudah terpasang di kode dan sekarang diam (silent).
Daftar nama event ada di scripts/audio_manager.gd (dictionary "streams").
Cara memasang suara akan didokumentasikan di ringkasan akhir project —
intinya: satu file .ogg dipasangkan ke satu nama event, tanpa mengubah
kode gameplay.
