# Supernova

Game jam entry — IFEST 2026  
Tema: **Chain Reaction**

2D top-down arena shooter. Kumpulkan musuh, picu ledakan berantai,
dan kejar chain setinggi mungkin.

## Kontrol

| Aksi | Tombol |
|---|---|
| Gerak | WASD |
| Tembak | Mouse kiri / Space |
| Singularity | Q |
| Nuke | E |
| Restart | R |

## Menjalankan

Godot 4.7, renderer Compatibility. Buka `project.godot`, tekan Play.
